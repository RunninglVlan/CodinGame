## Competitive programming

I use CodinGame for more than completing isolated exercises. The challenges involve:

- Parsing and validating constrained inputs
- Graph traversal and search
- Dynamic programming and optimization
- Constraint solving
- Simulation and state-machine logic
- Working within strict runtime and output requirements
- Iteratively testing and improving solutions
- Geometry

The repository includes standard training puzzles and higher-difficulty challenges that require combining several algorithms or designing a complete search strategy.
